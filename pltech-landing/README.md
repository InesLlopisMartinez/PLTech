# PLTech landing page

Landing page editable en React + Vite para PLTech. Los contenidos están en español y la interfaz se adapta a móvil y escritorio.

## Empezar

1. Instala Node.js (18 o posterior).
2. En esta carpeta ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección local que indique Vite.

Para generar la versión de producción, ejecuta `npm run build`.

## Estructura

- `src/App.jsx`: página y componentes React (navegación, hero, servicios, resultados, proyectos, proceso, CTA, sobre nosotros y footer).
- `src/styles.css`: identidad visual, vistas de proyectos ilustrativas y estilos responsive.
- `src/main.jsx`: punto de entrada de React.

Las dos tarjetas de proyectos usan vistas CSS de ejemplo, no imágenes inexistentes. Sustitúyelas por capturas reales cuando estén disponibles. Actualiza también el correo `hola@pltech.es` por la dirección definitiva si cambia.
